An interactive Cricket Analytics Web App built using Streamlit, Pandas, and Matplotlib.
This project allows users to explore cricket data, analyze player performance, and visualize insights across multiple seasons.

🚀 Features
📊 Top Batsmen Analysis – View highest run scorers
🎯 Top Bowlers Analysis – Identify leading wicket-takers
👤 Player Dashboard – Detailed stats with performance graphs
⚔️ Player Comparison – Compare two players side-by-side
🏏 Team Statistics – Analyze team-wise performance
📅 Season Filter – Filter data by specific seasons
💬 Query-Based Input – Ask questions like:
top batsman
top bowler
player virat kohli
compare virat kohli and rohit sharma
team mi
